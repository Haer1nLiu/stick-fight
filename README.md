# 墨斗火柴人

水墨风的火柴人格斗网页游戏。黑色墨人对红色朱人，十几种招式可以自由连招。

**在线玩：<https://haer1nliu.github.io/stick-fight/>**

纯 HTML + CSS + JavaScript，没有任何依赖，下载后双击 `index.html` 也能玩。

## 模式

- **单人对战**：打电脑，简单 / 普通 / 困难三档，三局两胜，每回合 60 秒
- **双人对战**：两个人同一个键盘
- **训练场**：气永远是满的，按 `T` 切换木桩：站着 / 会格挡 / 会还手

## 招式（单人键位）

| 招式 | 按键 | 效果 |
|---|---|---|
| 移动 / 跳 / 蹲 | `A` `D` / `W`（空中再按二段跳）/ `S` | 二段跳会空翻 |
| 冲刺 | 双击方向 或 `空格` | |
| 格挡 | 按住 `L` | 被打中前一瞬间按下 = 完美格挡，对手僵直 |
| 三连拳 | `J` `J` `J` | 直拳 → 摆拳 → 升龙拳挑空 |
| 踢腿二连 | `K` `K` | 前踢 → 回旋踢，击倒 |
| 升龙拳 / 扫堂腿 | `S`+`J` / `S`+`K` | 挑空 / 扫倒 |
| 空中拳 / 飞踢 / 下砸 | 空中 `J` / `K` / `S`+`K` | 下砸落地有震波 |
| 冲撞 | 冲刺中 `J` | |
| 投技 | `U` | 格挡不了 |
| 气功波 | `I` | 消耗 25 气 |
| 必杀·百裂拳 | `O` | 消耗 100 气，撞中后连打八下 |

打中后可以马上接气功波或必杀；被挑飞的对手落地前都能继续追打。按 `Tab` 随时看招式表。

## 双人键位

| | 移动 | 拳 | 腿 | 格挡 | 投 | 气功波 | 必杀 | 冲刺 |
|---|---|---|---|---|---|---|---|---|
